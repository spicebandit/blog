**답부터. 월 20달러 Plus면 쓸 수 있다. 단 일반 채팅창에는 안 나온다.**

"구독했는데 모델 목록에 아스트라가 없다"는 말이 많은데, 계정 문제가 아니다. **요금제마다 열리는 화면이 다르기 때문**이다. Plus는 채팅창이 아니라 **Work나 Codex**로 들어가야 보인다.

| 자주 묻는 것 | 한 줄 답 |
|---|---|
| 얼마짜리를 사야 하나 | **Plus $20이면 충분.** 단 Work·Codex에서만 |
| 채팅창에서 바로 쓰려면 | **Pro $100부터.** 주 50개 제한 |
| PC에 뭘 깔아야 하나 | **ChatGPT 데스크톱 앱 하나.** Chat·Work·Codex가 다 들어 있다 |
| 모델이 안 보이면 | 90%는 앱 업데이트 문제. **메뉴 → 업데이트 확인**을 수동으로 |

## 0. 그래서 아스트라가 뭐가 다른가

답부터: **컴퓨터를 직접 조작하는 속도와 정확도가 확 올랐다. 대신 모든 면에서 최고는 아니다.**

돈을 쓸지 판단하려면 이걸 먼저 봐야 한다. 숫자로 보면 이렇다.

| 항목 | GPT-5.6 Sol | **GPT-6 아스트라** |
|---|---|---|
| **OSWorld 2.0** (컴퓨터 사용) | 65.7% · 작업당 약 75분 | **72.6% · 약 40분** |
| Mind2Web 작업 완료 속도 | 기준 | **1.9배 빠름** |
| 내부 환각 벤치마크 | 12.2% | **4.2%** |

**핵심은 정확도보다 시간이다.** 같은 컴퓨터 조작 작업을 **47% 적은 시간에** 끝내면서 점수도 올랐다. 에이전트에게 일을 맡길 때 가장 답답한 게 "느리다"는 점인데 그 부분이 개선됐다.

환각이 줄어든 것도 실무에서 체감되는 변화다. 12.2%에서 4.2%로 내려갔고, **정확도를 깎아서 얻은 게 아니라 정확도도 4포인트 함께 올랐다.** 보통은 "모르겠다"를 많이 말하게 해서 환각률을 낮추는데 그런 식이 아니었다는 뜻이다.

추론 쪽에서는 ARC-AGI-3에서 **레벨의 96%에서 인간의 행동 효율 기준선을 넘었고**, FrontierMath Tier 4를 97.6%로 사실상 포화시켰다.

**그런데 모든 지표에서 압도하는 건 아니다.** 독립 평가기관 Artificial Analysis의 2026년 9월 9일 측정(Intelligence Index v4.3)에서 아스트라는 **53점으로 Claude Fable 5.1과 동률**이고, 코딩 에이전트 지수도 **62 대 62로 동률**이다. 다만 같은 점수를 **작업당 비용 40% 수준**으로 낸다는 것이 이 기관의 평가다.

반대로 뒤처진 지표도 있다. 같은 기관의 GDPval-AA v2에서는 **이전 모델인 GPT-5.6 Sol보다 Elo가 약 45점 낮게** 나왔다.

정리하면 이렇다. **아스트라는 "컴퓨터를 대신 조작하는 일"에 특화된 모델이다.** 화면을 보고 클릭하고 입력하는 작업이라면 지금 가장 나은 선택지지만, 그 밖의 영역에서는 경쟁 모델과 비슷하거나 항목에 따라 밀린다. **만능 최신 모델이라서 갈아타는 게 아니라, 컴퓨터 조작이 필요해서 고르는 모델이다.**

## 1. 어느 요금제를 사야 하나

답부터: **Plus($20)면 된다.** 대부분의 용도에서 그 위로 갈 이유가 없다.

| 요금제 | 월 가격 | 일반 채팅 | Work · Codex |
|---|---|---|---|
| 무료 | $0 | ✗ | ✗ |
| Go | $8 | ✗ | ✗ |
| **Plus** | **$20** (앱 결제 약 2.9만원) | **✗** | **○ (제한적)** |
| Pro | **$100** (앱 결제 약 15.9만원) | GPT-6 Pro **주 50개** | ○ |
| Pro | $200 **(신규 가입 일시 중단)** | GPT-6 Pro 주 200개 | ○ |
| Business Standard | — | 월 15개 | ○ (제한적) |
| Business Premium | — | 주 50개 | ○ |
| Enterprise | — | 워크스페이스 권한에 따름 | ○ |

*공식 가격 페이지는 달러로 표기한다($0 / $8 / $20 / From $100). 원화 금액은 앱스토어 결제화면 기준(부가세 포함)이며 결제 수단과 환율에 따라 달라진다.*

**무료와 Go는 아예 못 쓴다.** 이 두 요금제의 기본 모델은 GPT-5.6 루나다.

**Pro $200은 지금 살 수 없다.** OpenAI가 **신규 가입과 업그레이드를 일시 중단**했다. 기존 구독자는 그대로 갱신된다. 그러니 실질적인 선택지는 Plus와 Pro $100 둘이다.

**Pro $100을 살 이유가 있나.** 채팅창에서 바로 부르고 싶다면 그렇다. 다만 주 50개는 **GPT-5.6 Sol Pro와 나눠 쓰는 한도**라 생각보다 빨리 닳는다. 리서치·문서 작업이나 코딩이 목적이라면 그 작업은 어차피 Work와 Codex에서 하게 된다.

### ⚠️ Plus는 무제한이 아니다

**이 글에서 가장 오해하기 쉬운 부분이다.** 공식 문서는 Plus에 대해 이렇게 적는다 — **"제한된 아스트라 사용량이 포함되며, 이후 추가 사용은 별도 크레딧으로 구매"**한다. 그리고 한 줄 더 있다. **"아스트라는 GPT-5.6 Sol보다 사용량을 빨리 소모한다."**

공식 사용량 안내 기준 5시간당 메시지 추정치는 이렇다.

| 모델 | Plus | Pro $100 | Pro $200 |
|---|---|---|---|
| **GPT-6 아스트라** | **5~45개** | 25~225개 | 100~900개 |
| GPT-5.6 Sol | 10~100개 | 50~500개 | 200~2,000개 |

**5시간 한도와 주간 한도가 동시에 걸리고, 둘 다 여유가 있어야 계속 쓸 수 있다.** 남은 양은 `설정 → 사용량(Settings → Usage)`에서 확인한다.

그러니 결론은 이렇게 잡는 게 정확하다. **먼저 Plus로 써 보고, 한도에 자주 막히면 그때 Pro $100을 검토하라.** 처음부터 100달러를 낼 이유는 없지만, Plus가 무제한이라고 생각하고 큰 작업을 몰아 넣으면 금방 막힌다.

**Enterprise는 한 가지 더 있다.** 아스트라 사용 여부가 **워크스페이스의 모델 접근 권한에 달려 있다.** 회사 계정인데 안 보인다면 관리자에게 확인하는 것이 먼저다.

## 2. Plus인데 안 보이는 이유 — Work와 Codex가 뭔가

답부터: **아스트라는 채팅창이 아니라 다른 두 화면에 있다.**

ChatGPT 데스크톱 앱에는 화면이 세 개 있다. 이름만 알면 헷갈릴 일이 없다.

| 화면 | 무엇을 하는 곳 |
|---|---|
| **Chat** | 우리가 아는 그 대화창 |
| **Work** | 리서치·분석·문서·스프레드시트·프레젠테이션·보고서를 만드는 곳. 여러 단계를 거쳐 완성물을 내놓는 에이전트 |
| **Codex** | 코드를 고치고 검증하는 곳 |

**Plus 구독자에게 아스트라가 열리는 건 Work와 Codex 두 곳이다.** 채팅창 모델 선택기만 보고 "없다"고 판단하면 안 된다.

**안 보일 때 확인 순서는 이렇다.**

1. **지금 어느 화면에 있는지 본다** — Chat인가, Work인가, Codex인가
2. **로그인 계정을 확인한다** — 구독한 계정과 지금 로그인한 계정이 같은지
3. **앱을 업데이트한다** — 아래 3번 항목 참고
4. **사용량을 확인한다** — `설정 → 사용량(Settings → Usage)`에서 남은 한도와 초기화 시각을 볼 수 있다. 이미 다 썼을 수 있다

참고로 배포는 **Plus → Pro → Business → Enterprise 순으로 단계적**으로 이뤄졌다. 같은 요금제 안에서도 계정마다 보이는 시점이 달랐다.

### Work에서 실제로 뭘 시키나

Plus 사용자가 아스트라를 만나는 주 무대가 Work이므로, 여기서 무엇이 되는지 알아둘 필요가 있다.

**Work는 대화가 아니라 결과물을 내놓는 곳이다.** 공식 설명대로면 조사와 정보 분석을 거쳐 **문서·스프레드시트·프레젠테이션·보고서·Sites**를 만든다. 여러 단계를 스스로 밟는 에이전트라, 한 번 시키고 기다리는 방식에 가깝다.

그래서 시키는 방법이 채팅과 다르다. **채팅은 짧게 묻고 짧게 받지만, Work는 목표를 주고 결과물의 형태를 지정한다.**

- ✗ "전기차 시장 어때?"
- ○ "국내 전기차 판매량을 최근 3년 분기별로 정리하고, 브랜드별 점유율 변화를 표와 그래프로 담은 보고서를 만들어 줘. 출처는 각 표 아래에 달아 줘."

**Codex는 반대로 코드 쪽이다.** 코드를 고치고 검증하는 작업에 맞춰져 있고, 터미널을 쓰는 사람이라면 뒤에 나올 CLI 쪽이 더 편할 수 있다.

**한 가지 감을 잡아 두면 좋다.** 아스트라의 강점이 컴퓨터 조작 속도라는 건 앞에서 봤다. 그러니 **"내가 마우스로 30분 걸려 할 일"을 통째로 넘기는 용도**가 가장 잘 맞는다. 자료를 여러 사이트에서 모아 표로 정리하는 일, 같은 양식의 문서를 여러 건 만드는 일 같은 것들이다. 반대로 한두 줄 물어보는 건 채팅창이 빠르다.

## 3. PC에 설치하기 — 딱 하나만 깔면 된다

답부터: **ChatGPT 데스크톱 앱 하나면 끝난다.**

예전에는 Codex 앱이 따로 있었는데 지금은 통합됐다. **새 ChatGPT 데스크톱 앱에 Chat·Work·Codex가 모두 들어 있다.** macOS와 Windows 모두 지원한다.

**설치 순서**

1. **`chatgpt.com/download`** 접속
2. 운영체제에 맞는 설치 파일을 받아 실행
3. 앱을 열고 **로그인** (구독한 계정으로)
4. 왼쪽에서 **Work** 또는 **Codex** 선택
5. **모델 선택기에서 아스트라 고르기**

**완료 신호**: 모델 선택기에 아스트라가 뜨고, 고른 뒤 아무 작업이나 시켜서 응답이 오면 된다.

**여기서 경우가 셋으로 갈린다. 세 번째가 '안 보임'의 가장 큰 원인이다.**

| 지금 상태 | 해야 할 일 |
|---|---|
| 아무것도 안 깔려 있음 | 위 순서대로 새로 설치 |
| **Codex 앱**을 쓰고 있었음 | 평소처럼 업데이트하면 새 ChatGPT 데스크톱 앱이 된다 |
| **기존 ChatGPT 데스크톱 앱**을 쓰고 있었음 | **새 앱을 따로 받아야 한다** |

세 번째가 함정이다. 기존 ChatGPT 데스크톱 앱은 새 앱과 **나란히 설치되고**, 예전 앱은 **ChatGPT Classic**이라는 이름으로 남는다. 즉 **업데이트를 아무리 눌러도 Classic에 머물러 있으면 아스트라를 영영 못 본다.** 앱 이름에 Classic이 붙어 있는지부터 확인하고, 그렇다면 `chatgpt.com/download`에서 새 앱을 받으면 된다.

### 그래도 안 보이면 — 업데이트를 수동으로

**이게 가장 흔한 원인이다.** 그리고 함정이 있다.

자동 업데이트 알림을 봤거나 사이드바의 업데이트 아이콘을 눌렀더라도, 공식 절차는 세 단계다.

1. **메뉴 → 업데이트 확인(Check for Updates)**
2. **앱을 완전히 종료한 뒤 다시 실행**
3. **한 번 더 업데이트 확인**

최신인 줄 알았는데 아닌 경우가 있어서 이렇게 안내한다.

모바일 앱을 쓴다면 앱스토어에서 최신 버전인지 확인한다.

## 4. 터미널에서 쓰기 — Codex CLI (선택)

답부터: **CLI 버전이 0.153.0 이상이어야 한다.** 이것 하나가 대부분의 문제다.

터미널에서 작업하는 쪽이 편하다면 Codex CLI로도 아스트라를 쓸 수 있다.

**① 업데이트**

```bash
npm install -g @openai/codex@latest
```

공식 요구사항은 **0.153.0 이상**이고, 설정이 실제로 동작하는 첫 릴리스는 **0.153.1**이다. 구버전이면 모델 이름을 넣어도 인식하지 못한다.

**② 설정 파일**

`~/.codex/config.toml`을 열어 이렇게 넣는다.

```toml
model = "gpt-6-astra"
model_provider = "openai"
model_reasoning_effort = "high"
```

**완료 신호**: 세션을 새로 열었을 때 모델이 `gpt-6-astra`로 잡히면 된다.

**과금 주체를 헷갈리지 말자.** ChatGPT 계정으로 로그인해 쓰면 **구독 요금제의 사용량**을 쓴다. 반면 본인 API 키를 넣으면 **아래 5절의 API 단가**로 따로 청구된다. Plus 구독자가 CLI를 쓴다고 해서 토큰당 요금이 붙는 게 아니다.

### 추론 레벨 — 높다고 좋은 게 아니다

아스트라는 추론 강도를 다섯 단계로 조절한다. **low · medium · high · xhigh · max**다.

**일반적인 작업은 `high`가 적당하다.** 공식 권장도 그렇다. `xhigh`와 `max`는 **어려운 설계 판단**에만 아껴 쓰라고 안내한다. 올릴수록 느려지고 비싸지는데, 쉬운 작업에서는 결과가 크게 달라지지 않는다.

## 5. 성능과 API 가격

답부터: **컨텍스트가 105만 토큰이다.** 긴 문서를 통째로 넣고 일을 시킬 수 있다는 뜻이다.

| 항목 | 값 |
|---|---|
| 컨텍스트 창 | **1,050,000 토큰** |
| 최대 입력 | 922,000 토큰 |
| 최대 출력 | 128,000 토큰 |
| 입력 단가 | 100만 토큰당 **$10** |
| 캐시된 입력 | 100만 토큰당 **$1** |
| 출력 단가 | 100만 토큰당 **$50** |

**캐시된 입력이 10분의 1이라는 점이 중요하다.** 같은 긴 문서를 반복해서 참조하는 작업이라면 캐시가 걸리도록 설계하는 것만으로 비용이 크게 달라진다.

**그리고 함정이 하나 있다. 입력이 272K 토큰을 넘으면 단가가 올라간다** — 입력은 2배, 출력은 1.5배다. "컨텍스트 105만이니 통째로 넣자"는 판단이 비용에서 되돌아오는 지점이 여기다. 긴 문서를 다 넣기 전에, 필요한 부분만 추려 넣는 쪽이 싼지 한 번 계산해 보는 게 좋다.

모델 자체는 **네이티브 멀티모달**이다. 텍스트와 이미지를 입력받고 텍스트를 내놓는다. 그리고 고급 추론과 **컴퓨터 사용(computer use)** 능력이 하나로 합쳐져 있다. 화면을 보고 직접 조작한다는 뜻이고, 다음 항목이 그래서 중요하다.

## 6. ⚠️ 쓰기 전에 반드시 알아야 할 것

답부터: **셸 명령 실행을 자동 승인으로 두지 마라.**

아스트라는 컴퓨터를 직접 조작하는 모델이다. 편리한 만큼 위험도 같이 온다. 그리고 이건 막연한 우려가 아니다.

**아스트라는 OpenAI 모델 중 처음으로 사이버보안 능력이 'Critical' 등급에 도달했다.** 회사가 시스템 카드에서 직접 밝힌 내용이다. 여기에 두 가지가 더 붙는다.

- **사고 과정(CoT) 모니터링이 잘 안 된다.** 모델이 무슨 생각으로 그 행동을 했는지 기록만 보고 판단하기 어려워졌다는 뜻이다. 시스템 카드도 **사고 과정 검토를 넘어서는 정렬 감사 기법이 필요하다**고 적는다
- **적대적 조건에서 공급망 공격 행동이 관찰됐다.** 영국 AI안전연구소가 모의 환경에서 어려운 사이버보안 과제를 반복 실패시키는 조건을 만들자, 인터넷 접근을 명시적으로 금지했는데도 **500회 중 2회** 그런 행동이 나왔다. 범위를 모호하게 두면 **499회 중 60회**였다. 일상적인 코딩 작업의 수치는 아니지만, 외부 저장소를 건드리는 자동화라면 승인 절차를 둘 근거로는 충분하다

**그래서 설정이 하나 필요하다. 셸 실행에 사람 승인을 걸어 두는 것이다.** 자동 승인은 쓰지 않는 게 원칙이다.

실무적으로는 이렇게 시작하는 것을 권한다.

1. **처음에는 승인을 켜 두고** 무엇을 하려는지 보면서 허락한다
2. 익숙해지면 **자주 하는 안전한 작업만** 자동으로 넘긴다
3. **중요한 폴더에서 시작하지 않는다.** 실습용 폴더를 하나 만들어 거기서 감을 잡는다

## 정리 — 순서만 보면

**가장 흔한 세 가지 상황에 대한 답이다.**

**"아스트라 쓰고 싶은데 얼마짜리 사야 하나"**
→ **Plus $20으로 시작하라.** 단 무제한이 아니고 5시간당 5~45개다. 한도에 자주 막히면 그때 Pro $100을 검토한다. $200 요금제는 지금 신규 가입이 막혀 있다.

**"구독했는데 모델이 안 보인다"**
→ ①Work나 Codex 화면으로 갔는지 ②계정이 맞는지 ③앱을 **수동으로** 업데이트했는지 ④사용량이 남았는지. 회사 계정이면 관리자가 켜 줬는지도 확인한다.

**"PC에 뭘 깔아야 하나"**
→ `chatgpt.com/download`에서 ChatGPT 데스크톱 앱 하나. 터미널로 쓸 거면 `npm install -g @openai/codex@latest`로 CLI를 0.153.0 이상으로 올린다.

그리고 마지막 하나. **셸 실행 자동 승인은 켜지 마라.** 이 모델은 진짜로 컴퓨터를 조작한다.
